# 🚀 PlaceMate

> An AI-powered student career, placement preparation, and resume management platform.

PlaceMate is a full-stack career management platform designed to help students prepare for placements by bringing their **student profile, skills, projects, certifications, coding profiles, coding problems, resumes, AI resume analysis, and AI resume generation** into one centralized platform.

The main idea behind PlaceMate is simple:

A student should not need to maintain their career information across multiple disconnected platforms.

Instead, PlaceMate provides one platform where students can:

- Maintain their complete career profile
- Manage projects
- Manage certifications
- Track coding profiles
- Track coding problems
- Upload existing resumes
- Analyze resumes using AI
- Generate targeted resumes using AI
- Generate professional resume PDFs
- Prepare their profile according to a target role
- Eventually use placement-oriented insights and recommendations
